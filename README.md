# Automated Reasoning Suite: SAT Solvers

A Python-based optimization suite implementing fundamental algorithmic paradigms for solving the Boolean Satisfiability Problem (SAT) in Conjunctive Normal Form (CNF). 

## 🧠 Algorithms Implemented

1.  **Resolution-Based Solver:** Explores the complete search space through iterative clause learning and resolvent expansion until contradiction (`UNSAT`) or saturation (`SAT`) is reached.
2.  **Davis-Putnam (DP):** Employs variable elimination strategies via pure literal elimination and systematic resolution.
3.  **DPLL (Davis-Putnam-Logemann-Loveland):** A complete, backtracking-based search algorithm featuring recursive backtracking, unit propagation, and deterministic simplification of CNF matrices.

## 🛠️ Technical Focus

* **Language:** Python 3.x
* **Concepts:** Formal Logic Verification, Boolean Algebras, Backtracking Search Tree Optimization, Unit Propagation.
